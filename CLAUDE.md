# Агент поиска авиабилетов

Репозиторий содержит агента, который ищет авиабилеты по запросу пользователя.

## Структура
- `.claude/agents/flight-search.md` — описание субагента `flight-search`: что спрашивать, как искать, как отвечать.
- `tools/search_flights.py` — бесплатный поиск на Aviasales Data API (Travelpayouts), кэш цен. Только стандартная библиотека Python 3.
- `tools/search_ignav.py` — живой поиск на Ignav API: цены за всех пассажиров, детали пересадок, ссылки на покупку. Платный после 1000 разовых бесплатных запросов.

## Как это работает
- Запрос идёт на `https://api.travelpayouts.com/aviasales/v3/prices_for_dates`.
- Токен лежит в настройках облачного окружения как network secret `TRAVELPAYOUTS_TOKEN`
  (хост `api.travelpayouts.com`, заголовок `X-Access-Token`, пустой префикс). Окружение само добавляет его в запрос.
  Скрипт токен не читает и не печатает.
- Данные берутся из кэша Aviasales: это цены из поисков пользователей за последние дни, а не живые тарифы.
  Для узких дат и редких маршрутов (например, из Мюнхена в Гоа) кэш часто пуст.

## Возможности инструмента
- Диапазоны дат (`2026-12-23..2026-12-25`) и списки аэропортов (`GOI,GOX`): одна команда перебирает все комбинации.
- `--legs`: туда и обратно как два билета в одну сторону.
- `--direct`, `--max-transfers N`: фильтр по пересадкам.
- Для прямых рейсов в одну сторону выводится UTC-время вылета и прилёта, по нему считают стыковки через хабы.
- Предохранитель `--max-requests` (по умолчанию 40) ограничивает число запросов за запуск.

## Как читать поля ответа (по наблюдениям)
- `duration_to`, `duration_back` — время в воздухе без пересадок.
- `duration` — всё время в пути с пересадками; для билета туда-обратно это сумма по обоим направлениям.
  Разница между `duration` и временем в воздухе — оценка времени на пересадки.
- `transfers`, `return_transfers` — число пересадок туда и обратно.
- Цена в выдаче относится к одному взрослому (в ссылках Aviasales указан один пассажир).
  Данных о городе и длительности каждой пересадки в ответе нет.

## Ignav: живые цены (`tools/search_ignav.py`)
- API: `https://ignav.com/api` (документация: https://ignav.com/docs, спецификация: https://ignav.com/openapi.json).
- Ключ лежит в окружении как network secret `IGNAV_API_KEY` (хост `ignav.com`, заголовок `X-Api-Key`, пустой префикс).
  Скрипт ключ не читает и не печатает.
- Платно: 1000 разовых бесплатных запросов, дальше $2 за 1000 успешных. Ошибки не оплачиваются. Запросы из кэша Ignav тоже оплачиваются.
  Один запрос — одна комбинация дат и пары аэропортов. Предохранитель `--max-requests` по умолчанию 12.
- Цена в ответе за ВСЕХ пассажиров поиска сразу (проверено: 1 взрослый и 2 взрослых + 2 ребёнка дают разные суммы).
- Для каждого сегмента есть аэропорты, местное время и UTC: инструмент считает время на каждой пересадке.
  Признак `requires_self_transfer` показывает отдельные билеты.
- `--links IGNAV_ID` возвращает ссылку на покупку (платный запрос; поля пассажиров и рынка в нём не принимаются).
- Ошибки: 401 нет ключа, 402 нужна оплата (https://ignav.com/dashboard), 429 месячный лимит расходов, 424/502/503 временные (инструмент повторяет).

## Проверка
`python3 tools/search_flights.py MOW LED --depart 2026-11`
Ошибка 401 значит, что токен не подставился: проверьте секрет и запустите новую сессию.
Для Ignav: `python3 tools/search_ignav.py MUC GOI --depart 2026-12-24 --adults 1` (один платный запрос).

## Правила
- Не записывайте токены, ключи и пароли в файлы репозитория. Репозиторий публичный.
- Агент не бронирует и не покупает билеты.
